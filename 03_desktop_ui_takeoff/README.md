# Desktop UI for Slab Quantity Take-Off

A modern desktop application built with `customtkinter` to provide a user-friendly interface for the slab quantity takeoff tool.

## Installation

You need to install the required dependency:

```powershell
pip install customtkinter
```

## Running the App

To run the application, navigate to this directory and execute:

```powershell
python app.py
```

## Usage
1. Click **Select DXF File** to choose your drawing.
2. Click **Run Take-Off** to process it.
3. The results will be displayed in the console window, and the generated Excel report and map image will be saved to the same directory as the original DXF file.
