Concrete QTO — Automation Strategy

End-to-end comparison: Excel VBA engine vs. Python desktop application for DXF quantity take-offs

Project: Concrete Qty Takeoff from DXF
Workflow Architecture
📊

Excel VBA Engine

Pure Excel · No Install
1
mod_DashboardUI — Upload & Confirm "Upload DXF" button on Excel dashboard. A popup dialog lets the user confirm which layers are Slabs, Walls, and Beams before processing.
2
mod_DXFParser — ASCII File Reader Opens the DXF as a text file line-by-line using VBA file I/O. Extracts LWPOLYLINE boundaries and TEXT labels into memory arrays.
3
mod_SlabExtractor — Area & Volume Matches text tags (e.g. "150 THK") to slab boundaries using spatial math. Calculates Area × Thickness = Concrete Volume (m³).
4
mod_WallExtractor — Wall Quantities Categorizes walls by layer name (Structural / Non-Structural). Calculates plan area and multiplies by floor height for concrete volume.
5
mod_BeamExtractor — Beam Quantities Filters geometries by beam layers, calculates plan area and running length for each beam element.
6
mod_ReportWriter — Sheet Tables Dumps all calculated quantities into formatted Excel tabs: Slab Details, Wall Summary, Beam Schedule, etc.
7
mod_MapVisualizer — In-Sheet Drawing Uses Shapes.BuildFreeform to draw color-coded polygon maps directly on the worksheet with thickness legends.
🐍

Python Desktop App

Standalone · High Performance
1
TakeoffApp (Qt UI) — Browse & Preview Desktop window built with PyQt. User browses a DXF; the app instantly loads an interactive CAD preview (pan/zoom/layer toggle).
2
ezdxf — Native CAD Parser Reads DXF files natively including binary formats, complex entities (Splines, Blocks, Hatches), and multi-version AutoCAD files.
3
slab_extractor.py — Area & Volume Same logic: spatial point-in-polygon match of text tags → slab boundaries → Area × Thickness = Volume. Handles cutouts automatically.
4
wall_extractor.py — Wall Quantities Separates Structural vs. Non-Structural by layer convention. Calculates running length and applies user-defined floor height for wall volume.
5
beam_extractor.py — Beam Quantities Scans beam layers, identifies cross-sections, computes running lengths and plan areas for the beam schedule.
6
matplotlib Visualizers — PNG Maps Renders high-resolution color-coded floor plan maps (Slab Map, Wall Map, Beam Map) as PNG images. Fast and unlimited in detail.
7
openpyxl — Excel Report Builder Writes a complete .xlsx from scratch — data tables, formulas, styled headers, and the PNG maps embedded as pictures in each sheet.
Python Libraries at a Glance
PyQt / Qt

Builds the desktop window, buttons, input fields, tabs, and the background worker thread that keeps the UI smooth.

ezdxf

The core DXF reader. Understands all AutoCAD formats natively — binary DXFs, complex entities, block groups, and arcs.

matplotlib

Plots the extracted geometries into professional, high-resolution PNG map images. No shape count limits.

openpyxl

Creates the final .xlsx report with formatted tables, summaries, and embedded map PNGs — no Microsoft Excel required.

Head-to-Head Comparison
Feature 📊 Excel VBA 🐍 Python App
DXF Format Support ASCII only — binary DXF will crash All formats — ASCII, binary, all AutoCAD versions
Complex Entities LWPOLYLINE only — Splines & Blocks ignored Full support — Splines, Arcs, Blocks, Hatches
Visual Map Output Excel Shapes (slow, bloats workbook) High-res PNG via matplotlib (fast, lightweight)
Performance on Large Files Freezes / crashes on 50MB+ files Background threading — always smooth
Interactive CAD Preview Not available Full pan, zoom, layer toggle in-app
Setup Required None — open and run inside Excel Python + libraries must be installed
Where Excel VBA Can Fail
⛔
Binary DXF

VBA parser reads text only. Any binary DXF will cause an immediate failure at the read step.

🧩
Complex Geometry

Splines, Blocks, Arcs and Hatches are invisible to the VBA parser — those quantities are silently skipped.

💾
Large File Size

Reading a 100MB+ DXF line-by-line in VBA will freeze Excel or throw an Out of Memory error.

🖼️
Visualizer Crash

Drawing 10,000+ polygon shapes on an Excel sheet bloats the file and commonly causes Excel to crash.
